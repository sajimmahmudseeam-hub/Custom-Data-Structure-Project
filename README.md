# Data Structures Assignment 2

## Project Overview
This project implements two fundamental data structures in Java:

- **Circular Queue** — a fixed-capacity, array-based FIFO data structure.
- **Binary Search Tree (BST)** — a tree structure supporting insertion, searching, deletion, traversals, minimum/maximum, and range search.

## Technologies
- Java
- IntelliJ IDEA
- Automated tests

## Project Contents
The source code, tests, scripts, and documentation are in the `Assignment2_Final_Project` folder.

## How to Run
1. Open the project in IntelliJ IDEA.
2. Use JDK 17 or newer.
3. Run `Main.java` to start the console application.
4. Run `test.bat` on Windows to execute the automated tests.
